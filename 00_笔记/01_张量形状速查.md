# 张量形状速查表

> 卡住的时候先看这张表。90% 的 bug 都是形状对不上。

## 记号

| 符号 | 含义 |
|---|---|
| B | batch size |
| T | 序列长度（时间步，`block_size`） |
| C | 嵌入维度 `n_embd` |
| nh | 注意力头数 `n_head` |
| hs | 每头维度 `hs = C / nh` |
| V | 词表大小 `vocab_size` |

## 前向传播全程

```
输入 idx                  (B, T)           整数 token id
  │
  ├─ wte(idx)             (B, T, C)        token 嵌入
  ├─ wpe(pos)             (T, C)   →广播   位置嵌入
  └─ 相加 + dropout       (B, T, C)
  │
  ▼ 每个 Block × n_layer
  ├─ ln_1                 (B, T, C)        形状不变
  ├─ c_attn               (B, T, 3C)       一次算出 Q/K/V
  ├─ split                (B, T, C) ×3
  ├─ view+transpose       (B, nh, T, hs)   ★ 最容易错的一步
  ├─ scores = q@k^T/√hs   (B, nh, T, T)    ★ 显存占用 O(T²)
  ├─ masked_fill + softmax(B, nh, T, T)
  ├─ att @ v              (B, nh, T, hs)
  ├─ transpose+view       (B, T, C)        ★ 必须先 .contiguous()
  ├─ c_proj + dropout     (B, T, C)
  ├─ 残差相加              (B, T, C)
  ├─ ln_2 → MLP           (B, T, C) 中间升到 (B, T, 4C)
  └─ 残差相加              (B, T, C)
  │
  ▼
  ln_f                    (B, T, C)
  lm_head                 (B, T, V)
  cross_entropy           logits.view(-1, V) vs targets.view(-1)
```

## 三个必错点

1. **`view` 之前忘了 `contiguous()`**
   `transpose` 只改 stride 不搬数据，之后的 `view` 会报
   `RuntimeError: view size is not compatible with input tensor's size and stride`。
   解法：`x.transpose(1,2).contiguous().view(B,T,C)`

2. **掩码维度对不上**
   掩码 buffer 是 `(1, 1, block_size, block_size)`，实际序列长 T 可能小于 block_size，
   必须切片：`self.bias[:, :, :T, :T]`

3. **推理时忘了只取最后一个位置**
   训练时 `logits` 是 `(B,T,V)`；推理若全算，会白白多算 T-1 次 `lm_head`（V 通常 5 万，浪费巨大）。
   正解：`self.lm_head(x[:, [-1], :])` —— 用 `[-1]` 而不是 `-1`，保留时间维。

## 参数量速算（GPT-2 small 配置：L=12, C=768, V=50257, T=1024）

```
token 嵌入   V*C      = 50257*768  ≈ 38.6M
位置嵌入     T*C      = 1024*768   ≈  0.8M
每层注意力   4*C*C    = 4*768*768  ≈  2.4M × 12 层 ≈ 28.2M
每层 MLP     8*C*C    = 8*768*768  ≈  4.7M × 12 层 ≈ 56.6M
输出头       与 token 嵌入共享（权重绑定），不再计入
------------------------------------------------
合计                                  ≈ 124M
```
经验公式：**参数量 ≈ 12 × L × C²**（不含嵌入）。
